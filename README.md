# Corporate Sales Data Analysis & Interactive Sales Dashboard

### 📌 Project Overview
An interactive sales dashboard built to analyze corporate sales performance, tracking core revenue metrics, product categories, and regional distribution.

### 🛠 Tools & Techniques Used
- **Microsoft Excel**: Pivot Tables, Pivot Charts, Dynamic Slicers, Report Connections, KPI Cards.
- **Data Visualization**: Column Charts, Doughnut Charts.
